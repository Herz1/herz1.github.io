把这个博客部署到 GitHub Pages 的完整笔记

2026-07-26 约 6 分钟 约 1600 字

本站的所有文件就是一个普通文件夹：双击 index.html 能看，扔到任何静态托管上也能看。这篇笔记记录把它变成「有域名的正经网站」的全过程——照着做一遍，十分钟内你的博客就能上线。

前置条件只有两个：装好 Git，注册一个 GitHub 账号。

第零步：本地先跑起来

纯静态站点的美德是本地即所得。两种方式任选：

  • 直接双击 index.html —— 全部功能可用（本站没有任何需要服务器的请求）。
  • 起个本地服务器（更接近线上环境，地址栏更好看）：
bash
# 方式 A：Python（Windows/macOS 一般自带或易装）
python -m http.server 4173

# 方式 B：Node
npx serve .

# 然后浏览器打开 http://localhost:4173

第一步：建仓库

去 GitHub 点右上角 New repository，只需要决定一个名字，两种方案：

仓库名上线后的地址适合
usagiyama-blog（任意名）你的用户名.github.io/usagiyama-blog/大多数人，一个账号可以开很多站
你的用户名.github.io你的用户名.github.io（根域名）把它当唯一主站

其他选项保持默认（Public、不勾 README），点创建。本站所有链接都用相对路径，所以两种方案都不用改任何代码。

第二步：推上去（三条命令）

在博客文件夹里打开终端：

bash
# 如果还没初始化过 git（本站仓库已内置首次提交，可跳过前两条）
git init -b main
git add -A && git commit -m "🍡 开张"

# 关联远端并推送（把 yourname 换成你的用户名）
git remote add origin https://github.com/yourname/usagiyama-blog.git
git push -u origin main

第三步：打开 Pages 开关

  • 进入仓库页面 → Settings → 左栏 Pages
  • Source 选 Deploy from a branch
  • Branch 选 main，目录选 /(root)，点 Save

等一两分钟，页面顶部会出现绿色的 Your site is live at …。恭喜开张 🎉

两个锦上添花的小文件（本仓库已带）：

  • .nojekyll —— 告诉 GitHub 别用 Jekyll 处理，部署更快更省心
  • 404.html —— 访客走错路时，会看到迷路的大福而不是冷冰冰的默认页

第四步（可选）：绑自己的域名

  • 在仓库根目录新建文件 CNAME，内容一行：blog.example.com
  • 去域名服务商加一条 DNS：blog 的 CNAME 记录 指向 你的用户名.github.io
  • 回到 Settings → Pages，填入域名并勾选 Enforce HTTPS

踩坑备忘

  • 页面 404：多半是仓库里没有根目录的 index.html，或者 Pages 分支选错。
  • 样式丢了：检查是不是用了以 / 开头的绝对路径——项目页会多一层 /仓库名/ 前缀，全部用相对路径就永远不会踩。
  • 改了没生效：Pages 有 CDN 缓存，等一分钟或强刷（Ctrl+F5）。
  • 字体加载慢：本站的霞鹜文楷走 jsDelivr CDN，离线或被墙时会优雅回退到系统字体，不影响使用。

就这么多。从今天起，这条商店街有了自己的门牌号。下一步计划：接入 Giscus 评论、写一个 GitHub Actions 自动生成 RSS——都会继续记在这本手帖里。
