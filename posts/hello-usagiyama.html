你好，兔山商店街：本站开张记

2026-07-01 约 5 分钟 约 1200 字

欢迎光临。这里是「兔山手帖」，一家今天刚挂上门帘的小店。店名偷师自《玉子市场》里的兔山商店街（うさぎ山商店街）——我一直觉得，个人博客最理想的样子，就是商店街上的一间小铺：不大，但什么都是自己挑的；不热闹，但常来的人都熟。

为什么要自己盖房子

在各种平台写了几年之后，我终于下决心搬出来，理由大概有三个：

  • 房子是自己的。平台会改版、会限流、会消失，而一个静态站点托管在 GitHub 上，只要仓库还在，它就在。
  • 装修自由。想要一条会点灯的商店街？想让看板娘住在右下角？在自己的地盘上，这些都只是「写不写」的问题，而不是「能不能」的问题。
  • 写作回归写作。没有推荐算法的凝视，不用琢磨标题党。写给愿意专程来的人看，这种感觉很像在小店里招呼熟客。

选料：为什么是纯静态、零依赖

动工之前我认真比较过几条路线：

方案优点代价
Hexo / Hugo + 主题生态成熟，开箱即用要装 Node/Go，魔改主题像拆别人家的墙
Astro / Next 等框架工程化能力强对一个小博客来说，是用挖掘机种花
纯 HTML/CSS/JS零构建、零依赖、完全可控所有东西都得自己写

最后选了第三条。「所有东西都得自己写」听起来是代价，但对一个想把博客当作品的人来说，这恰恰是乐趣本体。而且纯静态有个隐藏福利：把仓库下载下来双击 index.html，和线上域名访问的效果一模一样——本地即所得，部署零心智负担。

年糕店的哲学：材料越简单，手艺越藏不住。

商店街的图纸

整个站点的结构一目了然：

text
usagiyama-blog/
├── index.html          # 首页（商店街全景在这里）
├── archive.html        # 归档 · 时间轴 + 分类筛选
├── bangumi.html        # 追番页
├── friends.html        # 友链
├── about.html          # 关于
├── 404.html            # 迷路的大福
├── css/style.css       # 全站样式（昼夜两套配色）
├── js/data.js          # 文章索引：加文章只改这里
├── js/main.js          # 全部交互组件
└── posts/*.html        # 文章正文

发新文章的流程简单到不好意思写出来：复制一篇旧文改内容，再往 data.js 的数组里加一条记录。首页卡片、归档、搜索、上一篇/下一篇，全部自动更新。

开张 Checklist

  • ✅ 昼夜双场景的商店街全景（试试右上角的月亮按钮）
  • ✅ 看板娘大福入驻右下角（连点三下有惊喜）
  • ✅ 全站搜索、右键菜单、阅读进度这些小家电装修完毕
  • ✅ 部署到 GitHub Pages（完整笔记在这里）
  • ⬜ 评论区（打算接 Giscus，用 GitHub Discussions 存数据）
  • ⬜ 更多文章（在锅里，快蒸好了）

开张第一天，没有剪彩，只有一场自己给自己下的年糕雨。如果你路过这里，欢迎在友链页留下你的店铺地址——商店街嘛，邻居越多越热闹。
