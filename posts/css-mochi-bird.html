用纯 SVG 画一只圆滚滚的年糕鸟

2026-07-24 约 8 分钟 约 2100 字

本站右下角住着一只会眨眼的胖鸟，名叫大福。经常有朋友问：这是找画师约的稿吗？不是——它是十几个 SVG 基本图形叠出来的，全部代码不到 30 行，没有用任何图片。这篇把它拆开给你看。

先看成品（这只是活的，会眨眼）：

▲ 大福 · 本体（inline SVG + 两个 CSS 动画）

设计原则：一切从圆开始

治愈系角色设计有一条铁律：圆度即亲和度。观察《玉子市场》的德拉、各种吉祥物，共同点是找不到一个锐角。所以我们的素材清单只有三种东西：

  • <circle> / <ellipse> —— 身体、眼睛、腮红、脚
  • 二次贝塞尔曲线 Q —— 嘴巴、呆毛
  • 三次贝塞尔曲线 c —— 胸口的小爱心

配色也只有五个：奶油白 #FFF9F0、暖棕描边 #E0C6AC、腮红粉 #F8AFC5、橘子嘴 #F2A65A、爱心红 #E4573D。全部取自低饱和暖色区，这是「年糕感」的来源。

逐层拆解

第一层：身体与肚皮

svg
<!-- 影子先画，垫在最底下 -->
<ellipse cx="150" cy="138" rx="36" ry="6" fill="rgba(120,80,50,.14)"/>
<!-- 身体：一个大圆 + 描边就有了软乎乎的轮廓 -->
<circle cx="150" cy="80" r="40" fill="#FFF9F0" stroke="#E0C6AC" stroke-width="3.5"/>
<!-- 肚皮：颜色更深一档的椭圆，制造体积感 -->
<ellipse cx="150" cy="95" rx="25" ry="16" fill="#FFEFD6"/>

要点只有一个：肚皮不要描边。同一只鸟身上，描边只出现在最外轮廓，内部全用色块区分，画面立刻干净。

第二层：五官

svg
<!-- 眼睛：竖椭圆比正圆多一分呆萌 -->
<ellipse class="eye" cx="136" cy="72" rx="4.2" ry="4.6" fill="#4A3A30"/>
<!-- 嘴：两条 Q 曲线拼成的菱形软糖 -->
<path d="M142 78 Q150 69 158 78 Q150 87 142 78" fill="#F2A65A"/>
<!-- 胸口爱心：向《玉子市场》的「恋の花」致意 -->
<path d="M150 108 c-4.4 -5 -11.3 -1.2 -7.5 4.3
         l7.5 5.7 7.5 -5.7 c3.8 -5.5 -3.1 -9.3 -7.5 -4.3" fill="#E4573D"/>

腮红是全场性价比之王：两个半透明粉圆，直接把亲和度拉满。位置放在眼睛外下方，宁低勿高。

第三层：让它活过来

两个动画就够了，多了反而闹：

css
/* 呼吸般的上下浮动 */
@keyframes bob {
  0%, 100% { transform: translateY(0) }
  50%     { transform: translateY(-12px) }
}
/* 眨眼：97% 的时间睁着，一瞬间压扁 */
@keyframes blink {
  0%, 93%, 100% { transform: scaleY(1) }
  96%          { transform: scaleY(.08) }
}
.eye {
  animation: blink 4.8s infinite;
  /* 关键：让缩放以眼睛自身为中心 */
  transform-origin: center;
  transform-box: fill-box;
}

最容易踩的坑是 transform-box: fill-box——不写它，SVG 元素默认绕整个画布原点缩放，眨眼会变成「瞬移」。写了它，变换中心才落在眼睛自己身上。

进阶：从立绘到看板娘

把静态立绘升级成本站右下角的看板娘，只加了三样东西（源码见 js/main.js）：

  • 台词气泡：点击时从台词数组随机抽一句，CSS 弹簧曲线 cubic-bezier(.34,1.56,.64,1) 负责「弹出来」的手感
  • 连击彩蛋：500ms 内连点三下触发年糕雨（36 个随机大小的 SVG 年糕从天而降）
  • 请假按钮：右上角的 ✕ 可以让它下班，用 sessionStorage 记住，刷新不复活，重开浏览器又回来上班

比起 Live2D 看板娘（要加载几 MB 的模型和运行时），这只 SVG 鸟的成本是 0 请求、0 依赖、约 1.5KB——治愈感不输，性能白拿。

画圆并不难，难的是接受「就这么简单」。祝你也捏出自己的年糕鸟——欢迎把成品发给我，好的作品会挂进友链页。
