白天写代码，晚上追京阿尼。相信「日常系」不是没有故事，而是把故事熬成了汤。这家小店卖的是：技术笔记、圣地巡礼手账、追番碎碎念，以及偶尔的生活切片。

这家店是怎么盖的

全站 零框架、零构建、零依赖：只有 HTML + CSS + 原生 JS，托管在 GitHub Pages。

所有插画（首页商店街全景、封面、看板娘大福）都是手写的 SVG，音乐盒 BGM 用 Web Audio API 现场合成——所以整个仓库里没有一张图片文件、一个音频文件。

把仓库 clone 下来双击 index.html，效果和线上完全一致。
